# Project Language & Response Guidelines

## 1. Language Priority
- **Primary & Default Language**: **English** (Highest Priority).
- **Secondary Format**: **Tanglish** (Romanized Tamil written strictly in the standard English/Latin alphabet, e.g., "Innaiku movie ki 250 selavu").
- **No Tamil Script / Words**: Do NOT use pure Tamil script characters or Tamil script wording in responses, assistant dialogues, UI text, or code comments.

## 2. Voice & Conversational Assistant
- All spoken responses (`spokenText`) and UI display responses (`displayText`) produced by Zenith AI / Gemini must be in clean, friendly English.
- The voice parser supports inputs in English and Tanglish, and always parses & formats titles, items, and categories into standard English.

## 3. Code & Documentation
- Maintain all code, comments, docstrings, and documentation strictly in English.
