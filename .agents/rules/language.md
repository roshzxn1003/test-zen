# Language & Communication Rules

- **English Priority**: All conversation, code, and user-facing text must prioritize clear English.
- **Tanglish Support**: Understand Tanglish queries (Romanized Tamil written in English alphabet) and format responses in English (or Romanized Tanglish when requested).
- **No Tamil Script / Words**: Strictly avoid pure Tamil script characters (e.g. தமிழ்) or Tamil script wording across all outputs, AI models, prompts, and UI components.
